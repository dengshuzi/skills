# 术语表

| 术语 | 含义 |
| --- | --- |
| V字开发模型 | 一种把上游定义和设计交付物，与下游验证活动对应起来的开发模型。 |
| AI Native | 一种从流程设计上允许 AI 安全、重复、可度量地参与研发全生命周期的工程方式。 |
| 要件定義 | 需求定义。说明要实现什么、为什么需要、如何判断验收通过。 |
| 基本設計 | 基本设计。说明系统级行为、接口、数据流、边界和主要设计决策。 |
| 詳細設計 | 详细设计。说明组件级逻辑、数据处理、异常处理和实现指导。 |
| テスト仕様書 | 测试规格书。说明测试目的、条件、步骤、期望结果和证据。 |
| 追踪关系 | 连接需求、设计、实现、测试、缺陷和发布判断之间关系的能力。 |
| 评审关口 | 交付物进入下一阶段或成为基线前的检查和批准节点。 |
| 基线 | 已被批准、可作为后续设计、实现和测试依据的正式版本。 |
| 变更影响分析 | 分析某个需求、设计或代码变更会影响哪些交付物、测试、风险和发布判断。 |
