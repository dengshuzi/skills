# V字模型地图

## 阶段职责

| 阶段 | 核心问题 | AI Native 支援 | 人的决策 |
| --- | --- | --- | --- |
| 要件定義 | 用户、业务或运维上必须满足什么？ | 歧义检测、需求拆分、验收标准草案 | 需求批准 |
| 基本設計 | 系统行为、接口和边界如何满足需求？ | TBD | 架构和接口决策 |
| 詳細設計 | 各组件内部如何处理？ | TBD | 详细设计批准 |
| 実装 | 如何把设计落到代码或配置？ | TBD | 代码合并批准 |
| CI | 如何在提交后尽早验证实现质量？ | TBD | 门禁与反馈策略 |
| テスト | 实现是否符合已批准交付物？ | TBD | 质量判断 |
| リリース判定 | 当前版本是否可以发布？ | TBD | 发布决策 |

## 对应关系

| 左侧阶段 | 右侧对应 |
| --- | --- |
| 要件定義 | 受入 / リリース判定 |
| 基本設計 | システムテスト |
| 詳細設計 | 結合テスト |
| 実装 | 単体テスト |
